# دعوة خطوبة محمود وآية

## التشغيل
- فك ضغط الملف وافتح `index.html` في المتصفح، أو ارفع مجلد المشروع كاملًا إلى استضافة مواقع ثابتة.
- تظهر الصورة المصممة المرفقة أولًا كما هي كتصميم بصري كامل، مع زر «افتح الدعوة». عند الضغط عليه تظهر نسخة HTML تفاعلية فيها العد التنازلي وتفاصيل القاعة.
- ملف الموسيقى موجود في `assets/engagement-music.mp3`. يبدأ تشغيله بعد تفاعل المستخدم إذا سمح المتصفح.
- رابط الموقع وزر الاتجاهات ورمز QR مرتبطون برابط خرائط جوجل الذي زوّدني به المستخدم.

## الملفات
- `index.html`: الصفحة.
- `style.css`: تنسيق الصفحة.
- `script.js`: تبديل اللغة، الموسيقى، والعد التنازلي.
- `assets/invitation-design.png`: الصورة الكاملة التي تعرض التصميم المطلوب.
- `assets/reference-design.png`: صورة المرجع.
- `assets/qr-code.png`: رمز QR.
- `assets/engagement-music.mp3`: الموسيقى.

## صور القاعة
لم أضع صورًا غير موثقة على أنها صور حقيقية للقاعة. يمكن إضافة الصور الأصلية بالأسماء `venue-main.jpg` و`venue-2.jpg` و`venue-3.jpg` داخل `assets/` وستظهر في قسم القاعة.
