# دعوة خطوبة محمود وآية | Engagement Invitation

موقع دعوة خطوبة متجاوب عربي/إنجليزي، مبني باستخدام HTML وCSS وJavaScript بدون إطار عمل.

## التشغيل
1. فك ضغط `engagement-invitation.zip`.
2. افتح `index.html` في متصفح حديث. للحصول على أفضل نتيجة، ارفع المجلد كاملًا إلى استضافة صفحات ثابتة.
3. ملف الموسيقى المرفق موجود في `assets/engagement-music.mp3`، ويبدأ بعد الضغط على «افتح الدعوة» إذا سمح المتصفح بذلك.
4. زر خرائط جوجل ورمز QR يشيران إلى الرابط الذي زوّدني به المستخدم.

## صور القاعة
لم تُدرج صور القاعة الحقيقية لأن تعذر التحقق من صور أصلية من الرابط ضمن هذه الحزمة. قبل النشر:
- أضف صورة حقيقية باسم `assets/venue-main.jpg`.
- أضف صورتين باسم `assets/venue-2.jpg` و`assets/venue-3.jpg`.
- استبدل عناصر `.photo-placeholder` و`.mini-placeholder` في `index.html` بعناصر `<img>` تشير إلى الصور.

الصورة `assets/reference-design.png` هي صورة التصميم المرجعي المرفقة، للاحتفاظ بها والرجوع إليها وليست صورة موثقة للقاعة.
